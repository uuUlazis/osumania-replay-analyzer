# osu!mania Replay Analyzer

本地 osu!mania 回放分析工具：解析回放与谱面，重建每一颗音符的判定与按键偏移，
给出准确率、偏移统计、一致性核查与可视化回放预览。同时支持浏览 stable 与 lazer
的本地成绩库。全部数据在本地处理，不访问网络。

![主界面：总览统计 · 时间轴 · 回放预览](https://i.ibb.co/W4jpcB5c/screenshot-main.png)

## 下载与运行

从 [Releases](https://github.com/uuUlazis/osumania-replay-analyzer/releases) 下载
ManiaReplayAnalyzer-v0.1.3.zip，解压后双击 ManiaReplayAnalyzer.exe（exe 需与 `frontend/dist` 文件夹保持相对位置）。

- 优先以内嵌窗口打开；失败时自动回退到系统默认浏览器（功能完全一致）
- 首次运行如遇 SmartScreen 提示：点「更多信息 → 仍要运行」即可
- 程序运行产生的状态与日志均写入本机，删除对应文件夹即可卸载干净

## 功能总览

### 回放分析

选择 .osr 回放与对应 .osu 谱面（皮肤文件夹、音乐文件均可选），点击「加载分析」：

- 六档判定计数、准确率、偏移统计（打早/打晚平均）与一致性核查
- 判定重建与回放内声明的计数高度一致；剩余的小幅差异会在诊断中如实标注
- 支持 stable 与 lazer 两种来源的回放

### 成绩库浏览

- stable：选择 scores.db（只读，绝不写入），自动定位同目录的回放与谱面；
  打开「回放列表」即可浏览全部成绩——日期、键数、曲名、曲师、难度、Mods、ACC、
  分数、星数、pp，支持按任意列排序
- lazer：绑定 lazer 数据目录即可浏览其中所有成绩
- 搜索：支持字段命令，例如 key=4（键数）、star>5（星数）、acc>=98（准度）、
  length<3:00（时长）、player=xxx（玩家）、mod=nc（Mod 筛选；支持组合如
  mod=hd,dt，mod=nm 为无 Mod，mod!=nc 为排除）。
  点击「搜索命令一览」可查看完整命令说明
- 选中一条成绩即可一键载入分析

### 回放预览

- 下落式预览，与音乐同步播放；支持跳转、拖动与选段
- 速率 Mod（DT/NC/HT 及自定义变速）正确处理：音乐变速播放，落速与原速一致；
  DT/HT 不变调、NC 升调，与 stable 表现一致
- 「判定显示」叠加：每次按键的位置与判定以颜色标注（300g 蓝、300 黄、200 绿、
  100 橙、50 玫红、MISS 红），命中的物件以对应判定色描边
- 「判定规则」可切换 stable（长条整条综合判定）与 ScoreV2（长条头尾分别判定）口径
- 支持加载皮肤（mania 皮肤格式），缺失的资源使用内置默认渲染

### 选段分析

在时间轴上按住右键拖动选择区间，即可查看该段的准确率、判定数、星数与偏移统计；
配合「左右手分析」可查看该段的分手数据。

### 左右手分析

分别统计左手与右手的判定数、准确率与打早/打晚平均偏差：

- 左半边轨道记左手，右半边记右手；奇数键时可通过开关指定中间键的归属
  （设置会记住，下次启动仍生效）
- 整场（全局）与所选区间（选段）均可查看

## 数据来源与隐私

- 回放文件：stable 为 Data\r 目录下的 .osr；lazer 成绩直接读取其数据目录
- 谱面：stable 从 Songs 目录读取；lazer 从数据目录关联
- 成绩库（scores.db）只读解析，绝不写入或修改
- 全部分析在本机完成，不联网上传任何数据

## 常见问题

- 双击后没有打开窗口：程序依赖 WebView2（Windows 10/11 一般自带）。
  启动失败会自动回退到默认浏览器打开；exe 旁生成的 mra_webview.log
  记录了具体原因，可参考压缩包内的排障说明
- 带 DT/NC 的成绩 ACC 与游戏内有细微差异：判定重建已对齐游戏内口径；
  若仍有偏差，很可能为replay记录误差，这个为无法修复的缺陷
- 某些 lazer Mod 的成绩无法完整分析：少数特殊 Mod（如随机、反转）依赖
  回放尾块携带的信息，缺失时会在界面上提示
